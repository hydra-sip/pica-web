# PICA Web

Repositorio para la aplicación web del proyecto **PICA** (Trabajo Práctico Integrador - SIP / UNLu).

## Descripción
Este repositorio contendrá la interfaz web y la lógica del cliente para el sistema PICA.

## Configuración y Desarrollo

### Requisitos previos
- [Node.js](https://nodejs.org/) (versión LTS recomendada)
- [Git](https://git-scm.com/)

### Instalación
```bash
# Clonar el repositorio
git clone https://github.com/hydra-sip/pica-web.git

# Acceder al directorio
cd pica-web
```
